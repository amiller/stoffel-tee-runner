# Mock data provenance

`mock-jobs.json` is **synthetic**, generated by
`crates/lobby/src/bin/gen-mock-data.rs`:

    ./scripts/build.sh run -p stoffel-lobby --bin gen-mock-data

The four `JobRecord`s exist only so the jobs view can group by every
`JobState` and render an empty `JobPolicy` as "unconstrained". They are signed
by a fixed throwaway key, carry no attestation material, and their job_ids are
obviously not content hashes (`6d6f636b…` = "mock-…"). They are never
presented as evidence. The bundle fixtures — real quotes, real collateral —
are `evidence/bundles/*.json` and are the only evidence-grade data the mock
serves.
